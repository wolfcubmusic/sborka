# СБОРКА — Электрический интеллект

Альтернативная визуальная система учебной платформы. Основные экраны: #dashboard, #lesson, #assignment. Материалы и прогресс сохранены как вспомогательные сценарии исходного прототипа.

Демонстрация: без авторизации, видео и отправки данных. Файлы не покидают устройство. Шрифты Wix Madefor Display, Onest, Tektur сохранены локально из Google Fonts вместе с лицензиями OFL; подключение к сети не требуется.


## Статус
Утверждено пользователем для включения в портфолио WOLFART в составе кейса «СБОРКА». Основные экраны: личный кабинет, видеоурок, практическое задание. Используется оригинальный логотип направления 01 из материалов синего лендинга, в белом отображении на тёмной панели. Направление 02 остаётся основной системой кейса, направление 01 — альтернативной. Мерч пока не включается; видео ожидаются отдельно.
